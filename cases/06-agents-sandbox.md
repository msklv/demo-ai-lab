# Кейс 06 — Агенты в специализированной песочнице

## Требования: модели на GPU

| Деплой в GPUStack | Состояние | VRAM | Действие человека в UI |
|---|---|---|---|
| `Qwen3Guard-Gen-4B` (ID модели неизменен; `0.6B` — только в кейсе 03) | **включить** (LLM агента — внешняя, через `llm-svc`) | ≈12.7 GiB | `Start` |
| `Qwen3.8-27B-UD`, `gemma-4-12B`, `whisper-turbo` | **выключить** | — | `Stop` |

**Вариант без стража:** если агент работает на локальной `gemma-4-12B` (tool-calling включён: `--enable-auto-tool-choice`, `--tool-call-parser gemma4`), то страж выключен, а внешние вызовы идут только из MCP-серверов (`ysrch.` ходит в Яндекс API сам, минуя `llm-svc`). Тогда набор: `gemma` + ничего, 12.6 GiB.

- 780M: не участвует.
- Внешний контракт для агента: `llm-svc.` (статический ключ) — tool-calling поддерживает `deepseek-flash`.

## Сценарий показа (тезисно)

1. **Тезис:** агент — это не «чат побольше», а цикл «решил → вызвал инструмент → посмотрел результат → решил снова»; изоляция нужна, потому что агент исполняет чужой текст.
2. Каталог инструментов: `mcp.demo-ai-lab.ru` — 6 серверов (`docling`, `yandex-search`, `firecrawl`, `github`, `kuvasz`, `ragflow`); агент получает их как MCP-инструменты, а не как захардкоженные вызовы.
3. Задача из зала (шаблон): «разбери PDF на стенде и найди в интернете, что это за стандарт» → в логе видно `tools/list`, вызов `docling` (документ → markdown), затем `web_search`.
4. Массовое чтение веба — тот же агент, `firecrawl`: `firecrawl_map` (какие URL есть) → `firecrawl_batch_scrape`/`_crawl` (N страниц одним вызовом) → `firecrawl_screenshot` (как страница выглядит). Проговорить: чужой HTML парсится в поде `fc`, а не рядом с агентом, приватные/LAN-адреса отбивает guard.
5. Ответ агента с опорой на источники; показать трейс: сколько шагов, какие инструменты, сколько токенов.
6. Песочница: отдельный namespace, `ResourceQuota` + `NetworkPolicy`, без доступа к кластерному API; у `dsh` права — пресеты процесса (`workspace-write`, `danger-full-access` запрещён). (По желанию) инструмент без прав — показать отказ и что агент не падает.

## Критерий успеха

Агент вызвал ≥2 инструмента (`docling` + `web_search`), вернул связный ответ, в трейсе видно всю цепочку; если показан `fc` — в трейсе есть вызов `firecrawl_*`, а в логе `fc` видно `tools/call`; ограничения песочницы (квоты/сеть) видны на объекте, а не на словах.
