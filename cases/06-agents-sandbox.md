# Кейс 06 — Агенты в специализированной песочнице

## Требования: модели на GPU

| Деплой в GPUStack | Состояние | VRAM | Действие человека в UI |
|---|---|---|---|
| `Qwen3Guard-Gen-4B` (ID модели неизменен; `0.6B` — только в кейсе 03) | **включить** (LLM агента — внешняя, через `llm-svc`) | ≈12.7 GiB | `Start` |
| `Qwen3.8-27B-UD`, `gemma-4-12B`, `whisper-turbo` | **выключить** | — | `Stop` |

**Вариант без стража:** если агент работает на локальной `gemma-4-12B` (tool-calling включён: `--enable-auto-tool-choice`, `--tool-call-parser gemma4`), то страж выключен, а внешние вызовы идут только из MCP-серверов (`ysrch.` ходит в Яндекс API сам, минуя `llm-svc`). Тогда набор: `gemma` + ничего, 12.6 GiB.

- 780M: не участвует.
- Внешний контракт для агента: `llm-svc.` (статический ключ) — tool-calling поддерживает `deepseek-flash`.

## Сценарий показа (тезисно)

1. **Тезис:** агент — это не «чат побольше», а цикл «решил → вызвал инструмент → посмотрел результат → решил снова»; изоляция нужна, потому что агент исполняет чужой текст.
2. Каталог инструментов: `mcp.demo-ai-lab.ru` — витрина, где опубликованы `docling` и `yandex-search`; агент получает их как MCP-инструменты, а не как захардкоженные вызовы.
3. Задача из зала (шаблон): «разбери PDF на стенде и найди в интернете, что это за стандарт» → в логе видно `tools/list`, вызов `docling` (документ → markdown), затем `web_search`.
4. Ответ агента с опорой на оба источника; показать трейс: сколько шагов, какие инструменты, сколько токенов.
5. Песочница: показать, где живёт рантайм (отдельный namespace, `ResourceQuota` + `NetworkPolicy`, без доступа к кластерному API) — «агент ограничен политикой, а не доверием».
6. (По желанию) одна и та же задача с инструментом, у которого нет прав — показать отказ и что агент не падает.

## Критерий успеха

Агент вызвал ≥2 инструмента (`docling` + `web_search`), вернул связный ответ, в трейсе видно всю цепочку; ограничения песочницы (квоты/сеть) видны на объекте, а не на словах.

## Подготовка до сцены (блокеры)

- **Рантаймы `qm` (`qm.demo-ai-lab.ru`) и Hermes (`hm.demo-ai-lab.ru`) не развёрнуты** — шаг 4 плана. Без рантайма показывать нечего.
- **«Песочница» пока не определена.** Дешёвый вариант: namespace + `ResourceQuota` + `NetworkPolicy` + запрет `ServiceAccount` с правами (день работы). Дорогой: gVisor/Kata — на четырёх мини-ПК с вложенной виртуализацией не гарантирован; решать в ADR явно.
- Модель для tool-calling: решить, внешняя (`deepseek-flash` + страж на карте) или локальная (`gemma-4-12B` без стража) — от этого зависит набор деплоев в UI.
- Qdrant/память агента, если нужна — отдельный бюджет RAM (сейчас не выделен).

## Фолбэк

Рантайм не готов → кейс показывается со слайда (архитектура цикла + пример трейса из прошлого прогона) и переносится на следующий раз; остальные пять кейсов от него не зависят. В программе кейс последний именно поэтому.
