# Кейс 06 — агенты в специализированной песочнице

## Требования: модели на GPU

| Деплой в GPUStack | VRAM | Действие человека в UI |
|---|---|---|
| `Qwen3Guard-Gen-4B` — LLM агента внешняя, через `llm-svc`, страж обязателен | ≈12.7 GiB | `Start` |

**Вариант без стража:** агент на локальной `gemma-4-12B` (tool-calling: `--enable-auto-tool-choice`,
`--tool-call-parser gemma4`), 12.6 GiB; тогда внешние вызовы идут только из MCP-серверов (`ysrch.` ходит в
Яндекс API сам, минуя `llm-svc`). Набор в UI зависит от выбора — от этого же зависит, что показывать.

- 780M не участвует. Внешний контракт для агента — `llm-svc.` (статический ключ); tool-calling поддерживает
  `deepseek-flash`.

## Сценарий показа

1. **Тезис:** агент — не «чат побольше», а цикл «решил → вызвал инструмент → посмотрел результат → решил
   снова»; изоляция нужна, потому что агент исполняет чужой текст.
2. Каталог инструментов: `mcp.demo-ai-lab.ru` (6 серверов — `docling`, `yandex-search`, `firecrawl`, `github`,
   `kuvasz`, `ragflow`); агент получает их как MCP-инструменты, а не как захардкоженные вызовы.
3. Задача из зала (шаблон): «разбери PDF на стенде и найди в интернете, что это за стандарт» → в логе видно
   `tools/list`, вызов `docling` (документ → markdown), затем `web_search`.
4. Массовое чтение веба — тот же агент, `firecrawl`: `firecrawl_map` (какие URL есть) →
   `firecrawl_batch_scrape`/`_crawl` (N страниц одним вызовом) → `firecrawl_screenshot`. Проговорить: чужой
   HTML парсится в поде `fc`, а не рядом с агентом, приватные/LAN-адреса отбивает guard.
5. Ответ агента с опорой на источники; показать трейс: сколько шагов, какие инструменты, сколько токенов.
6. Песочница: отдельный namespace, `ResourceQuota` + `NetworkPolicy`, без доступа к кластерному API; у `dsh`
   права — пресеты процесса (`workspace-write`, `danger-full-access` запрещён). (По желанию) инструмент без
   прав — показать отказ и что агент не падает.

## Критерий успеха

Агент вызвал ≥2 инструмента (`docling` + `web_search`), вернул связный ответ, в трейсе видна вся цепочка; если
показан `fc` — в трейсе есть вызов `firecrawl_*`, а в логе `fc` видно `tools/call`; ограничения песочницы
(квоты/сеть) видны на объекте, а не на словах.

## Подготовка до сцены

- Оба рантайма развёрнуты (23.11): `hermes` (`hm.`) и `dsh` (`dsh./launch`) за SSO. Блокер один —
  NetworkPolicy/границы песочницы `dsh` (W8).
- **`/extract` Firecrawl не включён** (Q-C2 в `firecrawl-spec`): структурированное извлечение по схеме
  показывать нечем, только markdown/обход/скриншоты.
