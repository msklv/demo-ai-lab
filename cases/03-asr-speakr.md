# Кейс 03 — транскрибация совещания: Speakr + whisper, саммари внешней моделью

## Требования: модели на GPU

| Деплой в GPUStack | VRAM | Действие человека в UI |
|---|---|---|
| Страж: исполнитель `Qwen3Guard-Gen-0.6B`, внешний ID — `Qwen3Guard-Gen-4B` | ≈1.4 GiB | `Start` |
| `whisper-turbo` (`faster-whisper` int8) | ≈2.3 GiB (util 0.15) | `Start` |

- Сумма ≈3.7 из 15.93 GiB. **Со стражем `4B` (12.74 GiB) кейс не собирается:** проверено 02.11 —
  `whisper-turbo` уходит в `replicas=0`, транскрибация падает `404 Model not found or no running instances
  available`. Поэтому здесь исполняет `0.6B` (ADR-0006 его и предусматривает), а `4B` остаётся для 02.
- **Ничего не перенастраивать:** внешний ID стража один, по нему зовут и плагин `llm-qwen-guard`, и
  потребители; смена версии не требует правок (`llm-proxy-spec` §P5).
- 780M не участвует. Наружу уходит только **текст** транскрипта — через `llm-svc.` (DLP + страж).

## Сценарий показа

1. **Тезис:** запись совещания не покидает стенд; наружу уходит только текст (и то через DLP-маршрут).
2. Гость загружает короткую запись 1–3 мин (mp3/m4a с телефона) на `spk.demo-ai-lab.ru` (SSO).
3. На экране транскрипт с таймкодами, язык определён автоматически.
4. Саммари и заголовок — внешней моделью через `llm-svc`: тот же защищённый маршрут, что в кейсе 02.
5. **Запас козырей:** заранее прогнанная 24-минутная запись (28.10: транскрипт 14 835 симв., саммари
   4 463 симв., 55 с) — если зал спросит «а длинное совещание?».
6. Сказать, чего нет: диаризации (спикеров) в выбранном коннекторе нет — только таймкоды.

## Критерий успеха

Запись в статусе `COMPLETED`, транскрипт и саммари непустые, время обработки озвучено; в логах `llm-svc`
виден вызов саммари, в логах `whisper-turbo` — транскрибация.

## Подготовка до сцены

- Переключение на внешнюю модель сделано 02.11 (`spk-spec` v1.8): `TEXT_MODEL_BASE_URL=https://llm-svc.demo-ai-lab.ru/v1`,
  `TEXT_MODEL_NAME=deepseek-flash`, `TEXT_MODEL_API_KEY` = ключ `llm-svc` в Secret `spk-secrets`. Страж должен
  быть поднят: если он лежит, `llm-svc` отдаёт `503` и саммари падает.
- Бюджеты токенов (v1.8): `TITLE_MAX_TOKENS=4000`, `SUMMARY_MAX_TOKENS=32000`, `EVENT_MAX_TOKENS=8000` —
  reasoning `deepseek-flash` списывается из `max_tokens`, при малых значениях контент приходит пустым.
- `AUDIO_UNSUPPORTED_CODECS=aac` (иначе `.aac` из диктофона валится «200 без текста»).
- Записей для зала — 2–3 коротких mp3, чтобы не тратить сцену на поиск файла.

## Фолбэк

`llm-svc` недоступен (стража нет / провайдер лёг) → вернуть `TEXT_MODEL_BASE_URL` на `api.` и включить
`gemma-4-12B` вместо стража: саммаризует локальная модель, содержание кейса не теряется — единственный
кейс, который переживает падение внешнего маршрута.

**Альтернативный набор (проверен, без внешнего маршрута):** `gemma-4-12B` + `whisper-turbo` (≈14.9 GiB),
страж и 27B выключены — кейс не зависит от провайдера, но и внешнюю LLM не показывает.
