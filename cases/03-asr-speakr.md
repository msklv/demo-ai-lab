# Кейс 03 — Транскрибация совещания (Speakr + Whisper) с внешней саммаризацией

## Требования: модели на GPU

| Деплой в GPUStack | Состояние | VRAM | Действие человека в UI |
|---|---|---|---|
| `Qwen3Guard-Gen-4B` | **включить** (саммари идёт через `llm-svc`) | ≈12.7 GiB | `Start` |
| `whisper-turbo` (`faster-whisper` int8) | **включить** | ≈2.3 GiB (util 0.15) | `Start` |
| `Qwen3.8-27B-UD`, `gemma-4-12B` | **выключить** | — | `Stop` |

- Сумма ≈15.1 из 15.93 GiB — **впритык**. Перед сценой проверить `nvidia-smi`: если страж и whisper не сосуществуют, поднять util стража вниз нельзя без пересоздания инстанса (см. README, п.1 «вход для ADR»).
- 780M: не участвует (эмбеддинги Speakr не нужны в лёгком режиме).
- Внешняя саммаризация: `llm-svc.` (статический ключ) — наружу уходит только **текст** транскрипта.

**Альтернативный набор (проверенный, без внешнего маршрута):** `gemma-4-12B` + `whisper-turbo` (≈14.9 GiB), страж и 27B выключены — саммари считает локальная модель. Тогда кейс не показывает внешнюю LLM, зато не зависит от провайдера.

## Сценарий показа (тезисно)

1. **Тезис:** запись совещания не покидает стенд; наружу уходит только текст (и то через DLP-маршрут).
2. Гость загружает короткую запись (mp3/m4a с телефона, 1–3 мин) на `spk.demo-ai-lab.ru` (SSO).
3. На экране: транскрипт с таймкодами, язык определён автоматически.
4. Саммари и заголовок — внешней моделью через `llm-svc`; показать, что это тот же защищённый маршрут, что и в кейсе 02 (DLP/страж/квоты).
5. **Запас козырей:** заранее прогнать запись на 24 минуты (проверено 28.10: транскрипт 14 835 симв., саммари 4 463 симв., 55 с) — если аудитория захочет «а длинное совещание?».
6. Сказать, чего нет: диаризации (спикеров) в выбранном коннекторе нет — только таймкоды.

## Критерий успеха

Запись в статусе `COMPLETED`, транскрипт + саммари непустые, время обработки озвучено; в логах `llm-svc` виден вызов саммари, в логах `whisper-turbo` — транскрибация.

## Подготовка до сцены (блокеры)

- **Переключение на внешнюю модель — сделано 2026-11-02** (`architecture/specs/spk-spec.md` v1.6): `TEXT_MODEL_BASE_URL=https://llm-svc.demo-ai-lab.ru/v1`, `TEXT_MODEL_NAME=deepseek-flash`, `TEXT_MODEL_API_KEY` = статический ключ `llm-svc` в Secret `spk-secrets`. Условие сцены: страж `Qwen3Guard-Gen-4B` поднят — иначе `llm-svc` отдаёт `503` (fail-closed), и саммари падает. Откат — `api.demo-ai-lab.ru` + `gemma-4-12B`.
- Проверить лимиты: `TITLE_MAX_TOKENS=1000`, `SUMMARY_MAX_TOKENS=2500`, `EVENT_MAX_TOKENS=1500` (при больших значениях — `400` по контексту, уже проходили).
- `AUDIO_UNSUPPORTED_CODECS=aac` (иначе `.aac` из диктофона валится «200 без текста»).
- Записей для зала — 2–3 коротких в открытом доступе стенда (mp3), чтобы не тратить сцену на поиск файла.

## Фолбэк

`llm-svc` недоступен (стража нет / провайдер лёг) → вернуть `TEXT_MODEL_BASE_URL` на `api.demo-ai-lab.ru` и включить `gemma-4-12B` вместо стража: кейс продолжается, просто саммаризует локальная модель. Это единственный кейс, который переживает падение внешнего маршрута без потери содержания.
