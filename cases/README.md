# Кейсы показа — индекс и правила

Одна карта, один показ, восемь кейсов: номер файла = очередь на сцене.
Модели переключает **человек в UI GPUStack** (`Model Service → Deployments → Stop/Start`) — скриптов
и `kubectl scale` нет намеренно, состояние живёт в БД GPUStack.

## Сюжет

Арка показа — **цена одной карты** и ответ на вопрос «что уходит наружу»:

1. **01** ставит планку: 27B со 128K контекста живёт на 16 ГБ — но только один, эксклюзивно;
2. **02** отвечает на «а если локального мало»: выход наружу есть, но только через DLP, стража и квоты;
3. **03–05** — три задачи, которые обычно отдают в облако: аудио (наружу уходит только текст),
   бумага (OCR на своём железе), поиск по своим документам (наружу — только отобранный контекст);
4. **06** — агент, исполняющий чужой текст: тот же защищённый контракт, но в песочнице;
5. **07** — картинка — тоже без облака: промпт и результат не покидают стенд;
6. **08** закрывает программу тем, что дороже всего: голос — биометрия, а не текст. Две TTS-модели
   озвучивают один и тот же вход подряд, и разницу слышно в зале.

Архитектурная подложка (слои, из которых собраны кейсы) — четыре шага стенда в корневом `README.md`.

**Кейс 06 сознательно повторяет набор кейса 02** (на карте только страж): после OCR (04) и RAG (05)
карта возвращается в проверенное состояние «внешний маршрут под защитой», и агент работает на том же
защищённом контракте, что и во втором кейсе.

**Кейсы 07 и 08 несовместимы с внешним маршрутом по другой причине:** карта уходит под эксклюзивную
диффузию (07) и TTS (08), как 27B в 01, страж гасится — `llm.`/`llm-svc.` отдаёт `503`; ни картинка,
ни голос периметр не пересекают, внешних вызовов нет. После 08 программа заканчивается.

**Восьмой — эксклюзивный и по очереди:** обе TTS-модели вдвоём не живут (бюджет ниже), поэтому
переключение внутри кейса — часть сценария, а не пауза.

## Переключения (делает человек в UI)

| Переход | Действия в `Model Service → Deployments` | Время |
|---|---|---|
| 01 → 02 | `Stop` 27B → `Start` страж | 1–2 мин |
| 02 → 03 | `Start` `whisper-turbo` (страж остаётся) | 30–60 с |
| 03 → 04 | `Stop` whisper, `Stop` страж → `Start` `GLM-OCR` | 1–2 мин |
| 04 → 05 | `Stop` `GLM-OCR` → `Start` страж, `Start` `bge-m3`, `Start` `bge-reranker-v2-m3` | 1–2 мин |
| 05 → 06 | **ничего**: если `bge`/реранк оставить включёнными на 780M, карта уже в наборе «только страж» | 0 |
| 06 → 07 | `Stop` страж → `Start` `Z-Image-Turbo` | 1–2 мин (замер 04.11: из прогретого состояния ≈60–70 с) |
| 07 → 08 | `Stop` `Z-Image-Turbo` → `Start` `Qwen3-TTS-1.7B-Base` | 1–2 мин (замер 25.11: 132 с) |
| 08 (внутри кейса) | `Stop` `Qwen3-TTS-1.7B-Base` → `Start` `CosyVoice3-0.5B` | 1–2 мин (замер 25.11: 111 с) |

Итого шесть переключений между кейсами и одно внутри 08. Старт 27B — самый долгий в обратную сторону
(40–90 с + загрузка весов), поэтому `Stop` 27B лучше запускать за минуту до конца кейса 01. Каждый
переход объявляется вслух («вот цена одной карты») и совмещается со слайдом, а не с паузой.

**Переход 07 → 08 — последний между кейсами**: после него ни страж, ни резиденты не возвращаются.
Диффузия и обе TTS прогреваются заранее (`07-image-gen.md` Z3, `08-tts-voice-clone.md` T3) —
`ImagePullBackOff` и 35-секундная пауза на сцене недопустимы.

**Главное следствие:** страж стоит на 5070 Ti (`ADR-0007` рев. 2026-11-02) и с `util 0.80`
занимает 80 % карты. Поэтому **внешний маршрут (`llm.` / `llm-svc.`) и локальная модель на одной карте
не живут вместе**: либо страж, либо `gemma`/27B; `gemma-4-12B` в программе — не участник, а резерв.

## Решения по ADR (2026-11-02)

1. **Страж остаётся на 5070 Ti, `Qwen3Guard-Gen-4B`, `util 0.80`** — перенос на 780M отклонён: карта
   нужна под RAG (`bge-m3` + реранк), а стражу ASR не нужен. Снижение util под медиа-кейсы не требуется:
   в кейсе 03 исполняет `0.6B` (≈1.4 GiB) под тем же внешним ID, поэтому пересоздание инстанса больше
   не ломает маршрут (адрес стража — через `api.demo-ai-lab.ru`, регистр `guard`). Запись — ADR-0007
   рев. 2026-11-02, ADR-0006 рев. 4.
2. **«Переключение моделей на демо не показывается» (ADR-0007, рев. 2026-10-28) — ОТМЕНЕНО.**
   Замена LLM на сцене — основное движущее звено показа: набор меняет человек в UI GPUStack,
   каждый `Stop`/`Start` объявляется со слайдом.
3. **Роль `gemma-4-12B`** — резерв/фолбэк вне программы (карта занята набором кейса), не участник.
4. **Задача, не ADR:** `GLM-OCR` (кейс 04) и `bge-m3`/реранк (кейс 05) в GPUStack заведены (06.11);
   остаётся показная механика — освободить карту и переключить набор (ADR-0007).

## Общие правила сцены

- Зал заходит по Wi-Fi на **LAN-адреса** (`.230`); сеть и пароль — `README.md`, «Подключение»; `doc.` — публичный демо-маршрут (конвертация), MCP-эндпоинты — только внутри кластера (ADR-0012), лимиты Higress на время показа.
- Демо-учётки Keycloak — пул (`demo01…`), не одна на всех: иначе квоты `ai-token-ratelimit` считаются на общий `x-consumer`, а в access-логе шлюза их не различить.
- Любой кейс, где участвует внешняя модель (02, 03, 05, 06), **требует включённого стража**: без него маршрут отдаёт `503 guard unavailable (fail-closed)`.
- **Кейсы 07 и 08 — исключение по стражу, а не по правилу:** `POST /v1/images/generations` и
  `POST /v1/audio/speech` минуют `ai-qwen-guard` (плагин текстовый, стоит на чат-маршруте), и это
  проговаривается вслух: наружу не уходит ни промпт, ни картинка, ни голос — модерировать нечего.
  Промпты и тексты на сцене заготовленные, референс — с согласия говорящего. Имена моделей в `/v1` —
  это **`ModelRoute`**: модель без маршрута отдаёт `404 Model not found` (`Z-Image-Turbo` — маршрут 12 →
  модель 15; `Qwen3-TTS-1.7B-Base` — 14 → 19; `CosyVoice3-0.5B` — 15 → 20; проверка — `GET /v2/model-routes`).
