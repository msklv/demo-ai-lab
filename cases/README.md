# Кейсы показа — индекс и правила

Одна карта, один показ, восемь кейсов: номер файла = очередь на сцене. Модели переключает **человек в UI
GPUStack** (`Model Service → Deployments → Stop/Start`) — скриптов и `kubectl scale` нет намеренно: состояние
живёт в БД GPUStack.

## Что даёт бизнесу

| # | Кейс | Что даёт бизнесу |
|---|---|---|
| 01 | [27B на одной карте](01-27b-one-card.md) | модель уровня 27B с контекстом 128K живёт на одной потребительской карте — без сервера за миллионы |
| 02 | [Прокси во внешнюю модель: DLP, страж, квоты](02-proxy-dlp-guard.md) | внешняя модель становится допустимой там, где ИБ иначе её запрещает: ПДн уходят плейсхолдерами, опасный ввод блокируется, расход ограничен квотой |
| 03 | [Транскрибация: Speakr + whisper](03-asr-speakr.md) | протоколы и интервью превращаются в текст и выжимку, а запись не покидает контур |

## Набор на карте и переключения

| # | Включено на 5070 Ti | Σ VRAM | Дальше в UI | Время |

| 02 | страж `Qwen3Guard-Gen-4B` | ≈12.7 | `Start` `whisper-turbo` (страж остаётся) | 30–60 с |
| 03 | страж `0.6B` под ID `Qwen3Guard-Gen-4B` + `whisper-turbo` | ≈3.7 | `Stop` оба → `Start` `GLM-OCR` | 1–2 мин |
| 04 | `GLM-OCR` | ~12.1 | `Stop` → `Start` страж + `bge-m3` + реранк | 1–2 мин |
| 05 | страж `4B`; `bge-m3` + реранк на 780M (≈2.8 GTT) | ≈12.7 | **ничего** (карта уже в наборе «только страж») | 0 |
| 06 | страж `4B` | ≈12.7 | `Stop` → `Start` `Z-Image-Turbo` | ≈60–70 с |
| 07 | `Z-Image-Turbo` (vLLM-Omni, fp8) — эксклюзивно | 12.4 / пик 15.3 | `Stop` → `Start` `Qwen3-TTS-1.7B-Base` | 132 с (замер 25.11) |
| 08 | `Qwen3-TTS-1.7B-Base` → `CosyVoice3-0.5B` — по очереди | 11.7 / 9.9 | конец программы | 111 с (внутри кейса) |

**Эксклюзивный набор (01, 07, 08)** — страж с карты снят, поэтому `llm.`/`llm-svc.` отдают `503`, внешних
вызовов в кейсе нет. Страж `4B` с `util 0.80` занимает 80 % карты: **внешний маршрут и локальная модель
вместе не живут** (`ADR-0007` рев. 02.11). `gemma-4-12B` (12.6 GiB) — резерв вне программы, не участник.

`Stop` 27B запускается за минуту до конца 01 — это самый долгий старт. Каждый переход объявляется вслух со
слайдом, а не паузой; диффузия и обе TTS прогреваются заранее (`07-image-gen.md` Z3, `08-tts-voice-clone.md`
T3), иначе на сцене `ImagePullBackOff` и 35 секунд тишины.

## Общие правила сцены

- Зал заходит по Wi-Fi на **LAN-адреса** (`.230`); сеть и пароль — `README.md`, «Подключение»; `doc.` —
  публичный демо-маршрут, MCP-эндпоинты — только внутри кластера (ADR-0012).
- Демо-учётки Keycloak — пул (`demo01…`): иначе квоты `ai-token-ratelimit` считаются на общий `x-consumer` и в
  access-логе неразличимы.
- Любой кейс с внешней моделью (02, 03, 05, 06) **требует включённого стража**: без него `503 guard
  unavailable (fail-closed)`. В 07 и 08 страж обходится сознательно — `/v1/images/generations` и
  `/v1/audio/speech` минуют `ai-qwen-guard` (плагин текстовый, стоит на чат-маршруте); это проговаривается
  вслух: наружу не уходит ни промпт, ни картинка, ни голос.
- Имена моделей в `/v1` — это **`ModelRoute`**: модель без маршрута отдаёт `404 Model not found` (проверка —
  `GET /v2/model-routes`).
