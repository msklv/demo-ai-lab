# Кейсы показа — индекс и правила

Одна карта, один показ, шесть кейсов. Файлы пронумерованы **в порядке показа**: номер = очередь на сцене.
Переключение моделей делает **человек в web-интерфейсе GPUStack** (`Model Service → Deployments → Stop/Start`),
скриптов и `kubectl scale` для этого нет намеренно (состояние живёт в БД GPUStack).

## Сюжет

Арка показа — **цена одной карты** и ответ на вопрос «что уходит наружу»:

1. **01** ставит планку: 27B со 128K контекста живёт на 16 ГБ — но только один, эксклюзивно;
2. **02** отвечает на «а если локального мало»: выход наружу есть, но только через DLP, стража и квоты;
3. **03–05** — три задачи, которые обычно отдают в облако: аудио (наружу уходит только текст),
   бумага (OCR на своём железе), поиск по своим документам (наружу — только отобранный контекст);
4. **06** — агент, исполняющий чужой текст: тот же защищённый контракт, но в песочнице.

Переходы не прячутся: каждый `Stop`/`Start` — реплика «вот цена одной карты», совмещённая со слайдом.
Архитектурная подложка (слои, из которых собраны кейсы) — четыре шага стенда в корневом `README.md`.

**Кейс 06 сознательно повторяет набор кейса 02** (на карте только страж). Это решение повествования:
после OCR (04) и RAG (05) карта возвращается в уже проверенное состояние «внешний маршрут под защитой»,
и агент работает на том же защищённом контракте, который показывали вторым кейсом.

## Переключения (делает человек в UI)

| Переход | Действия в `Model Service → Deployments` | Время |
|---|---|---|
| 01 → 02 | `Stop` 27B → `Start` страж | 1–2 мин |
| 02 → 03 | `Start` `whisper-turbo` (страж остаётся) | 30–60 с |
| 03 → 04 | `Stop` whisper, `Stop` страж → `Start` `GLM-OCR` | 1–2 мин |
| 04 → 05 | `Stop` `GLM-OCR` → `Start` страж, `Start` `bge-m3`, `Start` `bge-reranker-v2-m3` | 1–2 мин |
| 05 → 06 | **ничего**: если `bge`/реранк оставить включёнными на 780M, карта уже в наборе «только страж» | 0 |

Итого четыре физических переключения. Старт 27B — самый долгий в обратную сторону (40–90 с + загрузка весов),
поэтому `Stop` 27B лучше запускать за минуту до конца кейса 01. Каждый переход объявляется вслух
(«вот цена одной карты») и совмещается со слайдом, а не с паузой.

## Бюджет 5060 Ti (15.93 GiB) — факты на 2026-11-02

| Деплой | Что резервирует | Откуда цифра |
|---|---|---|
| `Qwen3Guard-Gen-4B` (страж кейсов 02/05/06, внешний ID модели) | **≈12.7 GiB** (`--gpu-memory-utilization 0.80`, ctx 32768) | спека инстанса в GPUStack |
| `Qwen3Guard-Gen-0.6B` (страж **только кейса 03**, тот же внешний ID) | **≈1.4 GiB** | инстанс `Qwen3Guard-Gen-0.6B-3ihgo`, 2026-11-02; `4B` с ASR на одной карте не уживается |
| `gemma-4-12B` (локальный чат) | ≈12.6 GiB (util 0.68) | замер 28.10 |
| `whisper-turbo` (ASR) | ≈2.3 GiB (util 0.15) | замер 28.10 |
| `Qwen3.8-27B-UD` (BeeLlama, IQ3_S + kvarn4) | **15.1–15.6 GiB, только эксклюзивно** | `beellama-rtx5060/DEPLOY-REPORT.md` |
| `bge-m3` + `bge-reranker-v2-m3` (RAG) | на **780M** ≈3.1 GiB, карту не занимают | ADR-0007 |

**Главное следствие:** страж стоит на 5060 Ti (`ADR-0007` рев. 2026-11-02) и с `util 0.80`
занимает 80 % карты. Поэтому **внешний маршрут (`llm.` / `llm-svc.`) и локальная модель на одной карте
не живут вместе**: либо страж, либо `gemma`/27B. Из этого собран порядок кейсов, и `gemma-4-12B` в
программе — не участник, а резерв.

## Решения по ADR (2026-11-02)

1. **Страж остаётся на 5060 Ti, `Qwen3Guard-Gen-4B`, `util 0.80`** — перенос на 780M отклонён: карта
   нужна под RAG (`bge-m3` + реранк), а стражу ASR не нужен. Снижение util под медиа-кейсы не требуется:
   в кейсе 03 исполняет `0.6B` (≈1.4 GiB) под тем же внешним ID, поэтому пересоздание инстанса больше
   не ломает маршрут (адрес стража — через `api.demo-ai-lab.ru`, регистр `guard`). Запись — ADR-0007
   рев. 2026-11-02, ADR-0006 рев. 4.
2. **«Переключение моделей на демо не показывается» (ADR-0007, рев. 2026-10-28) — ОТМЕНЕНО.**
   Замена LLM на сцене — основное движущее звено показа: набор меняет человек в UI GPUStack,
   каждый `Stop`/`Start` объявляется со слайдом.
3. **Роль `gemma-4-12B`** — резерв/фолбэк вне программы (карта занята набором кейса), не участник.
4. **Задача, не ADR (открыто):** `GLM-OCR` и `bge-m3`/реранк завести в каталог GPUStack — без них
   кейсы 04 и 05 не существуют.

## Общие правила сцены

- Зал заходит по Wi-Fi на **LAN-адреса** (`.230`), `doc.` и `ysrch.` без авторизации — лимиты Higress на время показа.
- Демо-учётки Keycloak — пул (`demo01…`), не одна на всех: иначе квоты `ai-token-ratelimit` считаются на общий `x-consumer`, а в access-логе шлюза их не различить.
- Любой кейс, где участвует внешняя модель (02, 03, 05, 06), **требует включённого стража**: без него маршрут отдаёт `503 guard unavailable (fail-closed)`.
