# Кейс 08 — озвучка с клоном голоса: два TTS на одной карте

## Требования: модели на GPU

| Деплой в GPUStack | VRAM (замер) | Действие человека в UI |
|---|---|---|
| `Qwen3-TTS-1.7B-Base` (id 19, маршрут 14, `vLLM 0.22.1 --omni`, `--stage-overrides {"0":0.32,"1":0.12}`) | 5,75 GiB простой, **11,66 GiB** после синтеза | `Start` перед кейсом |
| `CosyVoice3-0.5B` (id 20, маршрут 15, `--omni --trust-remote-code`) | 9,24 GiB простой, **9,91 GiB** после синтеза | `Start` **вместо** Qwen — второй ход |

- **Одна TTS-модель за раз:** по пулам стадий вдвоём не живут (арифметика ниже), поэтому `Stop`/`Start`
  внутри кейса — часть сценария, а не пауза.
- 780M не участвует: `vLLM-Omni` живёт на CUDA, а `gfx1103` официально не поддерживается vLLM.
- Внешний маршрут (`llm.`/`llm-svc.`) в это время не работает — страж выключен, fail-closed. `/v1/audio/speech`
  идёт мимо `ai-qwen-guard` (плагин текстовый, на чат-маршруте): текст и голос периметр не пересекают,
  модерировать нечего; референс — заранее записанный, не из зала без согласия.

## Сценарий показа

1. **Тезис на слайде:** голос — биометрия, а не текст; здесь он не уходит никуда, и это не «одна модель на
   пробу», а две на одном входе.
2. **Переключение 07 → 08 объявляется вслух:** `Stop` `Z-Image-Turbo` → `Start` `Qwen3-TTS-1.7B-Base`, ~2 мин;
   на экране — карточка модели и пулы стадий.
3. **Прогрев одной фразой** (вслух: «первый запрос всегда дольше — сейчас 35 секунд, дальше 7»).
4. **Референс:** гость читает 8 секунд (с согласия, вслух) или берётся записанный `tts-voice-clone-ref-01.wav`;
   текст 542 знака лежит на слайде.
5. `python3 scripts/tts_demo.py …` → **7,2 с**, играет 38 с звука; на слайде — тайминг и 11,66 GiB.
6. **Второй ход:** `Stop` Qwen → `Start` `CosyVoice3-0.5B` (~2 мин, «вторая модель, тот же вход»), тот же
   текст → **9,8 с**; зал слушает разницу.
7. **Цифры:** 542 знака, 7,2 / 9,8 с на прогретой модели, 34,7 / 17,5 с на холодной, 11,7 / 9,9 GiB, две
   модели рядом не живут (15,0 GiB простой + активации).
8. **Ограничения вслух:** ударение модель не понимает (`за́мок`/`замо́к`), качество клона зависит от
   транскрипта референса, LoRA и диаризации нет; клон чужих голосов — только с письменным согласием.

## Критерий успеха

`POST /v1/audio/speech` через `api.` → `200`, файл `audio/wav` 24 кГц mono; на **прогретой** модели 542 знака
синтезируются **≤10 с** (замер 7,2 / 9,8 с); пик VRAM **≤12 GiB** (11,66 / 9,91); 0 `CUDA out of memory` и
0 рестартов пода за прогон.

## Замер 2026-11-25: один текст, обе модели

Референс `architecture/specs/tts-voice-clone-ref-01.wav` (8,08 с, 16 кГц mono), текст **542 знака**
(`tts-spec` §7), `language: Russian`.

| | `Qwen3-TTS-1.7B-Base` | `CosyVoice3-0.5B` |
|---|---|---|
| Запрос | `x_vector_only_mode: true`, без `ref_text` | `ref_audio` + `ref_text` (обязателен) |
| **Первый (холодный) запрос** | **34,7 с** → 39,60 с звука | **17,5 с** → 33,48 с звука |
| **Второй (прогретый)** | **7,2 с** → 38,40 с звука (0,19× реального времени) | **9,8 с** → 22,24 с звука |
| Файл | 1 900 844 Б — байт-в-байт как прогон 22.11 | 1 607 084 Б (`ref_text` условный — см. T1) |
| VRAM после | 11,66 GiB | 9,91 GiB |

Первый запрос после старта в 3–5 раз дольше прогретого, поэтому **на сцене модель прогревается одной короткой
фразой до показа**. Cosy на условном `ref_text` выдаёт разную длину звука от прогона к прогону (22,2 / 33,5 с)
— это не тайминг-метрика, а признак, что транскрипт референса нужен настоящий.

## Бюджет VRAM на 5070 Ti (15,92 GiB) — замер, а не расчёт

`vllm-omni` занимает **пул на каждую стадию** (доля карты), а не заявку от весов; при синтезе к пулу
добавляются активации.

| Модель | Пулы стадий | Простой | После синтеза | Влезает ли сосед |
|---|---|---|---|---|
| `Qwen3-TTS-1.7B-Base` | `{"0":0.32,"1":0.12}` | 5,75 GiB | **11,66 GiB** | нет: 11,7 + 9,9 = 21,6 > 15,92 |
| `CosyVoice3-0.5B` | дефолт (talker 0.4 + flow/code2wav 0.2) | 9,24 GiB | **9,91 GiB** | нет: простой 5,75 + 9,24 = **15,0 GiB**, запаса 0,9 GiB — синтез его съедает |

Проверено на железе: пока Cosy занимает карту, `whisper-turbo` (2,3 GiB) висит в `pending` 2+ минуты — второй
инстанс на закреплённую `k8s-04:cuda:0` не садится. Урезать пулы дальше нельзя: talker `Qwen3-TTS` весит
1,92 GiB, при пуле 0,16 стадия падает (`Available KV cache memory: 0.0 GiB`).

## Как развёрнуто (проверено 22–25.11)

| Шаг | Значение |
|---|---|
| Источник | каталог GPUStack, **без кастомного бэкенда и своего образа** (решение владельца 22.11): `qwen3-tts-12hz-1.7b-base`, `Fun-CosyVoice3-0.5B-2512` |
| Бэкенд | `vLLM` **0.22.1** + `--omni`, раннер `gpustack/runner:cuda13.0-vllm0.22.1` |
| Веса | GPUStack качает с HF сам (`/var/lib/gpustack/cache/huggingface/<repo>/`) — 4,23 + 1,9 ГиБ |
| Размещение | `gpu_selector: k8s-04:cuda:0`, `gpus_per_replica: 1` |
| Публикация в `/v1` | `ModelRoute` **14** → `Qwen3-TTS-1.7B-Base` (19), **15** → `CosyVoice3-0.5B` (20) |
| Ключ зала | `tts-demo` (id 29), `allowed_model_names` — только эти две модели; значение — в `gpustack-admin.local.md` |
| Старт → `running` | **132 с** (Qwen), **111 с** (Cosy) при прогретых весах; первый в жизни старт ≈9 мин (pull образа 9,85 ГБ) |

## Контракт (фактический, vllm-omni 0.22.1)

```
POST /v1/audio/speech
{ "model": "Qwen3-TTS-1.7B-Base" | "CosyVoice3-0.5B",
  "input": "текст", "language": "Russian", "response_format": "wav",
  "ref_audio": "data:audio/wav;base64,…",
  "ref_text": "транскрипт референса",     // CosyVoice3 — обязателен
  "x_vector_only_mode": true }             // Qwen3-TTS Base — вместо ref_text
→ 200 audio/wav (24 кГц, mono) · 400 без ref_text/x_vector_only_mode
```

Реестра голосов (`voice: <id>`) в этой версии нет: голос задаётся референсом в каждом запросе. Скрипт для
зала — `scripts/tts_demo.py`, он же проверка приёмки.

## Подготовка до сцены

- **T1. Транскрипт референса (`voices/<id>.txt`) — открыт.** Настоящего текста записи нет, поэтому клон Cosy
  в файлах 22.11 и 25.11 **не показательный**. Лечится прогоном `whisper-turbo` в одиночку (рядом с Cosy он
  не планируется) и перегенерацией файла.
- **T2. Согласие — открыт.** Чей голос в референсе и как цитируется согласие — записать до показа.
  Клонирование третьих лиц и публичных людей без письменного согласия не делаем.
- **T3–T5 — закрыто 25.11:** разница холодного и прогретого запроса зафиксирована (обязательна фраза-прогрев
  на каждой модели); ключ `tts-demo` выдан; обвязка (этот файл, `cases/README.md`, `tts-spec`, ADR-0007)
  обновлена, `scripts/check_doc_links.py` → 0.

## Фолбэк

1. **Cosy не поднялась / качество хуже ожидаемого** → кейс одной моделью: Qwen-клон + слайд со сравнением по
   таблице (второй ход и переключение внутри кейса убираются).
2. **Ни одна TTS не стартует** → слайд с цифрами и **готовые файлы прогона** (`tts-demo-*.wav` в
   `architecture/specs/`): «что уже синтезировано на этой карте», живого синтеза нет.
3. **Кончилось место под веса/образ** → `df -h /` и `ctr -n k8s.io images ls` до `Start`, как в кейсе 07.
