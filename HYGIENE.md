# Гигиена публикации (HYGIENE)

Репозиторий публичный: коммит остаётся в открытой истории навсегда. Правило действует на доки,
спеки, ADR, скрипты и их комментарии, манифесты, диаграммы (SVG/Excalidraw), тестовые фикстуры,
примеры команд, сообщения коммитов, вывод health-скриптов. Гейт — `scripts/hygiene_scan.py`,
процедура коммита и пуша — `AGENTS.md`.

## 1. Запрещено (STOP)

| Класс | Что именно | Куда уходит вместо репо |
|---|---|---|
| Секреты | пароли, токены (`ghp_*`, `github_pat_*`, `hf_*`, `AKIA*`, `sk-*`), приватные ключи (`BEGIN … PRIVATE KEY`), содержимое `.env` | `*.local.md`, `.env`; в кластере — Secret |
| MAC-адреса | MAC устройств, привязка «этот MAC = этот хост», OUI-привязки узлов | `inventory.local.md` |
| Внешние IP | публичный адрес площадки, аплинка, egress; адреса чужих сетей площадки; IP живых сервисов вне стенда | роль без адреса: «Uplink — сеть площадки, адреса не публикуются» |
| Геоданные | координаты, GPS/EXIF в фото, адрес и название физической площадки, всё, что привязывает узел к месту | `*.local.md`; фото — перекодировать без EXIF |
| Персональные данные | ФИО третьих лиц, телефоны, паспорт/СНИЛС/ИНН, резюме, ответы кандидатов, переписка, чужие e-mail, логины с фамилией | `~/hermes-home/hr/` (вне репо), `*.local.md` |
| Обход блокировок и VPN | истории «как обошли», схемы и ключи VLESS/Reality/Xray/Happ, инструкции по VPN-обходу | `*.local.md`; в публичном тексте — статус без механики |
| Отчёты по ИБ и уязвимости | описание дыры, условия эксплуатации, PoC и payload'ы, шаги воспроизведения, «что открыто без аутентификации», слабые конфиги (пароли/хеши, режимы без пароля, широкие allowlist'ы), результаты сканов, критичность, план устранения до внедрения | `security/<дата>-<тема>.local.md` |

ИБ-класс отдельно: найденная уязвимость в публичном репо — карта для атакующего. В публичном тексте
(спека, ADR, борд состояния) допустимы **факт и статус** («периметр служебных путей требует
доработки, внешний вход закрыт security group»), нейтральная ссылка «детали — локальный отчёт ИБ от
<дата>, вне репозитория» и архитектурное решение (PROXY protocol, выделенный порт, allowlist) — без
описания того, что именно открыто и как это обойти. Правило действует и на диаграммы, комментарии
скриптов и текст вывода health-скриптов: проверка может остаться, сообщение — «не закрыто, детали в
локальном отчёте».

Исключение из ПДн — **данные автора репозитория, опубликованные им самим** (имя, публичный e-mail,
профиль GitHub, публичный бренд стенда). Всё, что относится к другому человеку, — ПДн.

## 2. Публикуется осознанно

- LAN стенда (`192.168.10.0/24`, `10.20.20.0/26`), IP узлов `k8s-01…k8s-05` — операционная
  документация (`network-map-detail.md`, `architecture/ARCHITECTURE.md`).
- Настройки MikroTik — без логина, пароля и ключей Wi-Fi.
- Бренд `demo-ai-lab.ru`, версии, теги и digest'ы, публичные диапазоны CDN/резолверов, TEST-NET
  (`192.0.2.x`, `198.51.100.x`, `203.0.113.x`).
- Демо-фикстуры с очевидно ненастоящими данными (`+7 916 123-45-67`, `user-test@…`).

## 3. Проверка

```bash
./scripts/hygiene_scan.py            # гейт: добавленные строки staged-диффа
./scripts/hygiene_scan.py --tree     # всё дерево (tracked + untracked)
./scripts/hygiene_scan.py --history  # история всех коммитов (медленно)
```

Коды: `0` — STOP нет (REVIEW может быть), `1` — есть STOP, `2` — сканер не отработал (usage/git) →
вердикт недействителен, перезапускать.

Сканер видит сам: секреты и присвоение значений, MAC, внешние IPv4 (LAN стенда, loopback, TEST-NET,
публичные резолверы и anycast-CDN разрешены), координаты, ПДн-маркеры, ИБ-маркеры, VPN/обход
(REVIEW), логин «юзер@хост» (REVIEW), приватный файл в индексе git.

Остаётся человеку:

1. ФИО и логины с фамилией — по контексту: имя автора публикуется, чужие — нет.
2. `git diff -- .gitignore` перед широким `git add -A`: снятое правило = файл уедет в коммит.
3. Медиа: EXIF/GPS вырезать перекодированием; проверять блоб в индексе (`git cat-file -p :<path>`).
4. Бинарные форматы (диаграммы, `.key`/`.pptx`) — текст на подложке глазами.
5. Сообщение коммита: без адресов, логинов, ФИО, «как обошли».
6. Ссылки: `python3 scripts/check_doc_links.py` — 0 битых.
7. Ложные срабатывания ИБ-маркеров: «эксплуатация» в смысле сопровождения («выведен из
   эксплуатации»), версии и хеши.

## 4. Приватные файлы

`inventory.local.md`, `*.local.md`, `*.local.pem`, `.env*` — правила `.gitignore`, не список имён:
новый `*.local.md` подхватывается сам. Значения читаются скриптами (`scripts/*_secrets.sh`) в
переменную и в вывод не печатаются: `cat` приватного файла в лог — такая же утечка, как коммит.

## 5. При хите

- STOP — не коммитить: значение в `*.local.md` (`security/*.local.md` для ИБ), в публичном тексте
  роль без значения; не нужно и там — удалить.
- REVIEW — решает человек; по умолчанию считать данные.
- Хит в уже запушенном файле — назвать файл и коммит, предложить ротацию затронутых ключей; перепись
  истории (`amend`, `git filter-repo`, `--force-with-lease`) — только по явной команде.
