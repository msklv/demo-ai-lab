Демонстрационный стенд AI Lab для визуализации работы ИИ-агентов и on-prem LLM/GPU-вычислений.
Принцип утилитарности: локальная обработка предпочтительна, наружу передаётся только то,
что не представляет ценности.

## Реестр идей для реализации

Формат: одна идея — 1–2 предложения (что даёт и при каком условии берёмся). Статусы:
`кандидат` — ждём условия, `в плане` — есть фаза/спека, `отклонено` — только по новым обстоятельствам.

- **KAI Scheduler** (`кандидат`) — [repo](https://github.com/kai-scheduler/KAI-scheduler), Apache-2.0,
  CNCF sandbox, v0.18.6 (15.10.2026): второй планировщик рядом с kube-scheduler — gang scheduling,
  иерархические очереди с квотами и fairshare, GPU sharing, topology-aware.
  Берёмся при ≥2 конкурирующих GPU-ворклоадах на карту или второй GPU-ноде; сейчас блокеры —
  нужен NVIDIA GPU Operator (на стенде драйвер ставит Ansible + CDI), `nvidia.com/gpu`
  в кластере не публикуется, GPUStack через KAI не планируется.
