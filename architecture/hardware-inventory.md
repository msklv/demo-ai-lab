# Инвентаризация железа нод: диски, ресурс, прошивки

Хронологический журнал замеров оборудования стенда (в отличие от `ARCHITECTURE.md` — это
не проектное решение, а состояние железа «на дату»). Новая дата замера = новый снимок
в раздел «Хронология», текущее состояние держится в верхней таблице.

**Правило съёмки:** репозиторий публичный — серийные номера, MAC-адреса, UUID GPU и прочая
идентификация устройств в этот файл НЕ записываются; **все серийники хранятся только в
`inventory.local.md`** (gitignored). Команды снимать полями (grep по нужным ключам), а не
полный вывод `smartctl -a` / `lsblk -o SERIAL` / `dmidecode`: serial там всегда в выводе —
вырезка должна происходить на этапе захвата, а не перед коммитом (AGENTS.md репо).

Решение: **не прошиваем**. Официальных BIOS для этих плат GMKtec не публикует вообще;
единственная свежая сборка (K12) — неофициальная, прошивка «на свой страх и риск» без
гарантии возврата, а стенд — демо-оборудование. Скрытое меню Alt+F5 на K12 безвредно,
если когда-нибудь понадобится тонкая настройка TDP/UMAM — использовать его, не трогая
прошивку. Мониторинг: периодически перепроверять
[gmktec.com/pages/drivers-and-software](https://www.gmktec.com/pages/drivers-and-software)
(официальный канал, если что — появится там).

**Сетевые контроллеры (все ноды, ×2):** Realtek RTL8125 2.5GbE (rev 05), драйвер ядра
`r8169`, firmware NIC `rtl8125b-2_0.0.2 07/13/20` (снято на k8s-02 через `ethtool -i`,

## Паспорта дисков (документация)

### AirDisk 512GB SSD (k8s-02, k8s-03, k8s-04)

- OEM Shenzhen **Longsys** (sales@longsys.com), контроллер **Maxio MAP1202**, NVMe 1.4,
  PCIe Gen3 x4, безбуферный (HMB), M.2 2280.
- Заявленный **TBW = 256 TB** (512GB-версия; 256GB→128TB, 1TB→512TB), MTBF 1 500 000 ч.
  Даташит P1144 rev. A2 (2026-03):
  <https://www.positivoempresas.com.br/wp-content/uploads/2026/04/SSD_AIRDISK_PCIe_Gen3_M.2_2280_P1144.pdf>
  (PN `APF10-512G-P11441022A`; в даташите оговорка «TBW may differ according to flash
  configuration and platform» — для no-name типично завышать, для сравнения Kingston
  NV2 500GB = 160 TB).
- Вендорский сайт `airdisk.cc` недоступен; по прошивкам есть база
  <https://smarthdd.com/rus/database/AirDisk-512GB-SSD/> (скорость/температуры, TBW нет).
- Прошивки на стенде: `SN27911` ×2 (02, 03), `V1.2.3` (04) — в пределах линейки.

### ZSPEED SSD 512GB (k8s-01)

- **Публичной документации не существует**: вендорского сайта/даташита нет, в розничных
  каталогах и SMART-базах — только бенчмарк-агрегаторы без спецификаций (проверено
  2026-10-17: вендоры, smarthdd, nero-score, RU/CN/BR-розница).
- Единственная оценка ресурса — от контроллера самого диска: Percentage Used 11% при
  13.1 TB записано ⇒ внутренний рейтинг ≈ **119 TB** (≈вдвое ниже AirDisk).
- Пробег донора «офисный»: 13.1 TB ≈ 1–4 года обычной работы за ПК (типичная офисная
  запись 10–30 GB/сут). 11% получены ДО ввода узла в стенд (узел добавлен 2026-10-17);
  69 unsafe shutdowns — история питания донора, не дефект.

## Методика повторения замера

Умный счётчик — NVMe-поле Percentage Used (оценка контроллера, переживает перезагрузки,
в отличие от `diskstats`). На нодах стоит smartmontools; быстрый путь с консоли
(нужен sudo на нодах — см. `inventory.local.md`, не в git):

```bash
smartctl -a /dev/nvme0 | grep -iE \
  'Model Number|Firmware|Percentage Used|Available Spare|Data Units Written|Power On Time|Unsafe Shutdowns|Temperature:|Critical Warning'
```

- **2026-10-17 (вечер, F0):** LV `longhorn` 250G создан, ext4, fstab, смонтирован на
  k8s-02/03/04 (свободно в VG после нарезки ~124G/узел); k8s-01 — без LV, вне пула
  (политика износа выше); open-iscsi на всех четырёх.

Через Ansible (пароль из окружения, как в `ansible/` README):

```bash
ansible k8s_nodes -i ansible/hosts.cluster.yml -m shell \
  -a 'smartctl -A /dev/nvme0 | grep -iE "Percentage Used|Data Units Written"' --become
```
