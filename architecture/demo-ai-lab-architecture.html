demo-ai-lab · Архитектура стенда

demo-ai-lab.ru · Демо ИИ-агентов + on-prem LLM-инференс · кластер F0–F10 (kubeadm 1.35.9) · шаг 1 (GPUStack) и шаг 2 (owu · spk · doc · ysrch · mcp) развёрнуты 27–28.10 · впереди: Langfuse, RAGFlow, агенты шага 3

Физический слой — проверено

  • • Шлюз: MikroTik L009UiGS (RouterOS 7.24.5), LAN 192.168.10.0/24, WAN — uplink площадки; LAG до коммутатора: bond1 (ether7+8, balance-xor) ↔ Tenda порты 7–8
  • • 4 узла GMKtec (Ubuntu 24.04.4): k8s-01/.250 (добавлен 2026-10-17), k8s-02/.253, k8s-03/.254, k8s-04/.252 — через Tenda (порты 1–6)
  • • GPU: RTX 5060 Ti 16G на k8s-04 (с 2026-10-15): резидентно gemma-4-12B (util 0.68) + whisper-turbo; iGPU 780M — страж и эмбеддинги (план); BeeLlama — хостовый эталон (остановлена)
  • • Backend p2p 10.20.20.0/26 2.5G: k8s-02 ↔ k8s-03 (L2 проверено)
  • • В LAN — JetKVM (IP-KVM) 192.168.10.10, найдено 2026-10-29: web-UI на `:80`, HDMI-захват + USB HID, прошивка 0.5.7, DHCP без резервации
  • • Консоль: This Mac (DHCP), SSH по ключу

Что работает на 29.10.2026

  • • Кластер: kubeadm 1.35.9, 3 CP + worker 04, Cilium, Longhorn, NFD, cert-manager, metrics-server — F0–F10; Argo CD (GitOps) + Higress (VIP .230) + консоль с o11y
  • • SSO: Keycloak 26.8.1 ×2 + PG 17 (`auth.`, realm `dev`, K1–K7, 27.10)
  • • Шаг 1: GPUStack 2.2.3 (`api.`) — gemma-4-12B (ctx 8192) + whisper-turbo на 5060 Ti, SSO Keycloak (клиент `gps`), G0–G7
  • • Шаг 2 (28.10): Open WebUI (`owu.`), Speakr (`spk.`), Docling + MCP (`doc.`), Yandex Search MCP (`ysrch.`), каталог MCP 1.8.6 (`mcp.`, 2 сервера)
  • • Внешний путь — туннель: Cloudflare edge → cloudflared на VM (E7) → SSH-hop 02/03 → `.230`; LAN — split-DNS MikroTik

Впереди / риски

  • • План: RAGFlow (`rag.`: RAM на k8s-03, эмбеддинги на 780M), Langfuse (`lng.`, спека 29.10), агенты шага 3 — Hermes, qm, вынесенные рантаймы
  • • Guardrail ADR-0006 (Higress + `ai-data-masking` + Qwen3Guard-Gen-0.6B) — спека не написана; Лайт-LLM прокси, Qdrant, S3, Data Catalog, каталог скиллов — план
  • • JetKVM (`192.168.10.10`, найден 29.10) — authMode: noPassword: консоль KVM открыта любому в LAN (видео + клавиатура подключённой машины), лиз без резервации, целевой хост HDMI/USB не зафиксирован
  • • Приёмки не сняты: O4–O6 (owu), S5–S6 (spk), D4 (doc preset), M6/M8 (реестр — клиенту `mcp` нужен публичный тип); у Argo CD нет SSO (E9)
  • • Риски: внешняя VM — единая точка отказа; k8s-01 вне пула Longhorn; Prometheus консоли расширен до 2.5Gi (на 1Gi падал по ENOSPC)
