demo-ai-lab.ru · Демо ИИ-агентов + on-prem LLM-инференс · физический слой проверен живым аудитом (2026-10-17) · контейнер C2 — целевое состояние

Физический слой — проверено

  • • Шлюз: MikroTik L009UiGS (RouterOS 7.24.5), LAN 192.168.10.0/24, WAN — uplink площадки; LAG до коммутатора: bond1 (ether7+8, balance-xor) ↔ Tenda порты 7–8
  • • 4 узла GMKtec (Ubuntu 24.04.4): k8s-01/.250 (добавлен 2026-10-17), k8s-02/.253, k8s-03/.254, k8s-04/.252 — через Tenda (порты 1–6)
  • • GPU: RTX 5060 Ti 16G на k8s-04 (с 2026-10-15), инференс BeeLlama (Qwen3.8-27B, host-процесс)
  • • Backend p2p 10.20.20.0/26 2.5G: k8s-02 ↔ k8s-03 (L2 проверено)
  • • Консоль: This Mac (DHCP), SSH по ключу

Целевой контейнер C2 — план

  • • K8s на k8s-01/02/03/04 + ingress; GitOps: GitHub → Argo CD
  • • LLM в k8s — только GPUStack (OpenAI-API, наружу api.demo-ai-lab.ru); BeeLlama — хостовый эталон вне k8s на GPU k8s-04; vLLM/SGLang — перспектива
  • • Внешний путь — Cloudflare Tunnel (ADR-0004): зона в Cloudflare Free, коннекторы cloudflared на k8s-02/03 → ingress-VIP .230; LAN — split-DNS на MikroTik
  • • Сервисы: Speakr, RAGFlow, Open WebUI, OCR·Docling, BI; SSO — Keycloak
  • • Агенты: Hermes + qm (multiplayer-харнесс, yc-software/qm) + вынесенные рантаймы; трейсы — Langfuse; egress к внешним LLM — через прокси с сокрытием

Пробелы / риски

  • • K8s не поднят (F1 отложен владельцем): F0 закрыт 2026-10-17 на всех четырёх (containerd 2.2.1+CRI, swap off, LV longhorn 250G на 02/03/04, open-iscsi)
  • • k8s-01/k8s-04: enp3s0 не используется, не в p2p; узлы вне кластера до join
  • • Роль k8s-01 в кластере не назначена (32Gi RAM — максимум на стенде)
  • • DHCP-резервирования — сделано (.250/.253/.254/.252, bound); внешний доступ — решён через Cloudflare (ADR-0004): коннекторы 8/8 active, ждём активацию зоны (NS propagation reg.ru→Cloudflare)
