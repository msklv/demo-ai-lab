# AI Демо стенд — презентация (Slidev)

Колода для внутреннего показа `demo-ai-lab` (AI Демо стенд): стенд и архитектура → семь кейсов → три задания,
которые зал выполняет сам. Стиль — `presentations/gnivc-compact-design-system.md`
(dual-mode: фиолетовый dark для обложки/разделов/кейсов, белый light для контента и заданий).

## Запуск

```bash
cd presentations/internal-demo-2026-11
npm install
npm run dev          # http://localhost:3030, режим докладчика — клавиша P
npm run build        # статика в dist/ (любой статический хостинг)
npm run export       # PDF/PNG; нужен браузер для playwright: npx playwright install chromium
```

Требуется Node 18+ (проверено на 25.9). Колода самодостаточна: темы-пакета нет, layouts и
компоненты лежат рядом со `slides.md`.

## Структура

```
slides.md                 # вся колода: 22 слайда, заметки докладчика в <!-- -->
style.css                 # дизайн-токены + стили компонентов (по спеке дизайн-системы)
layouts/                  # cover, section-divider, case-title, split-dark, split-light,
                          # card-grid-4, numbered-row-list, step-flow, links, task,

                          # StandTopology, TaskStep, ServiceLink
```

## Что менять перед показом

- **Статусы и цифры** — сверять с `architecture/ARCHITECTURE.md` §7 и `cases/README.md`
  («Готовность кейсов»), не с этой презентацией.
- **Ссылки на сервисы** (слайд 09) — при новом хосте: `architecture/endpoints.md`.
- **Задания** — тексты в `slides.md`, блоки `<TaskStep>` и `<template #aside>`; ссылки в
  `<a class="task-link">`. Задания рассчитаны на LAN и пул учёток `demo01…`.
- **Заметки докладчика** — в `<!-- ... -->` под каждым слайдом; в режиме докладчика видны
  только на консоли.

## Правила репозитория

Репозиторий публичный: в слайды не попадают секреты, креды, MAC-адреса, публичные IP площадки и
детали найденных уязвимостей (AGENTS.md, раздел «Обязательная проверка чувствительности»).
Учётки в тексте — только как «пул `demo01…`», без значений.
