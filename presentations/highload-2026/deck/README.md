# Колода HighLoad++ 2026

22 слайда, 1280×720, без сборки: `index.html` + `style.css` + `qr.svg`. Собрана по
[`../highload-2026-style.md`](../highload-2026-style.md) (чёрное поле, красная геометрия, Montserrat)
и по [`../recommendations.md`](../recommendations.md): 4 кейса живьём, 3 слайдом, 2 задания, 3 переключения моделей.

## Открыть

```bash
open index.html                 # двойной клик тоже работает
python3 -m http.server 8000     # если нужен http://, а не file://
```

`←` `→` / `Space` — листать, `F` — полный экран, клик по правой половине — вперёд, по левой — назад.

## PDF для организаторов

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-pdf-header-footer \
  --virtual-time-budget=5000 --print-to-pdf=highload-2026.pdf \
  "file://$PWD/index.html"
```

PDF получается 22 страницы 1280×720; фоны и цвета сохраняются (`print-color-adjust: exact`).
